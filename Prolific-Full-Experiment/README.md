# Experimental Testing of Anticonformity to Depolarize Social System

To run the oTree code locally, point to the Prolific-Full-Experiment folder where the `settings.py` sits and run `otree devserver`. There are several apps to choose from, essentially, they only differ in the grouping criteria where N08 allows for creating neighborhoods of eight (with between-faction interactions or beta = 0.5) and neighborhoods of four (without between-faction interactions or beta = 0) while N04 only allows for the latter. When there is an 'A' specified, the neighborhoods of four only consist of those choosing the 'Against' solution (to interview the family first). 

You must have oTree installed to run the program. To install oTree, see the guide in https://otree.readthedocs.io/en/latest/install.html
