# Experimental Testing of Anticonformity to Depolarize Social System

# Paper
In preparation. (Preprint link: *soon*)

## Aim
We conducted preregistered experiment to test the computational model of depolarizing society with anticonformity.

## Data
Use the `07_combined_classified.csv` as the final cleaned data after all preprocessing steps.

## Installation
Clone the repository and installed the required Python packages:
```bash
pip install -r requirements.txt
```

## Preprocessing
To reproduce the preprocessing steps from the raw data, run:
```bash
python scripts/preprocess-publishable.py
```

## Directory
- `Clean_files`: preprocessed data from both framing conditions (political and nonpolitical)
- `Figures`: figures used in the paper
- `Nonpolitical/Political`: both raw and preprocessed data 
- `Simulation_results`: simulation results from the model
